# LocalRAG 用户手册

> 一份面向最终用户的操作指南。阅读完后，你应该能独立完成「配置 → 建库 → 上传 → 提问」全流程。

## 1. 安装

### 1.1 系统要求
- Windows 10 / Windows 11（64 位）
- ≥ 2 GB 可用磁盘空间（建议 5 GB+，用于存放向量数据）
- 网络连接（首次配置 API Key 与对话时需要）

### 1.2 安装步骤
1. 双击 `LocalRAG-Setup-x.x.x.exe`
2. 选择安装路径（建议使用默认）
3. 等待安装完成（约 10-20 秒）
4. 桌面双击「LocalRAG」图标启动

> 首次启动时，程序会在 `%APPDATA%\LocalRAG` 下创建数据目录与向量索引。**整个应用无需任何额外环境**（不依赖 Python、Node、Docker 等）。

> v1.1 升级说明：本版本起使用纯 JS 向量库（vectra），启动速度比之前版本更快，安装包体积更小。

## 2. 首次启动配置向导

### 2.1 配置 AI 服务
LocalRAG 不会内置任何 API Key，请先准备以下任意一家的账号：
- **OpenAI**（`https://platform.openai.com`）
- **DeepSeek**（`https://platform.deepseek.com`）
- **通义千问 DashScope**（`https://dashscope.aliyun.com`）

启动后进入「设置」→「AI 服务」：
1. 点击「添加 Provider」
2. 选择服务商，输入显示名
3. 填入 API Key（系统会保存到 Windows 凭据管理器，不会明文落盘）
4. 选择模型（Chat 与 Embedding 可分别设置）
5. 点击「测试连接」

### 2.2 选择默认服务
在「设置」→「常规」中，指定：
- 默认 Provider
- 默认 Chat 模型

## 3. 创建知识库

1. 左侧栏点击「＋ 新建知识库」
2. 输入名称（如「产品手册」）
3. 可选填写描述
4. 点击「创建」

知识库会出现在左侧列表中。

## 4. 上传文档

支持格式：`.pdf` / `.docx` / `.md` / `.txt`

1. 在「文档」面板点击「上传文档」或拖拽文件到窗口
2. 选择目标知识库
3. 等待解析与向量化（每 10 页约 3-5 秒）
4. 列表中状态变为「已就绪」即可检索

> **提示**：删除知识库会同时删除其下所有文档与向量，请谨慎操作。

## 5. 提问与对话

1. 顶部选择目标知识库
2. 在底部输入框中输入问题，按回车或点击「发送」
3. 回答会逐字流式输出，并附带「引用来源」
4. 可以继续在同一会话中追问，AI 会结合上下文
5. 点击「新建会话」开启新话题

### 5.1 引用来源
每条回答末尾列出最相关的 3-5 个文档片段，点击可跳转到原文段落。

### 5.2 复制 / 重生
- 鼠标悬停消息上，点击「复制」可复制 Markdown 原文
- 点击「重新生成」会用相同上下文再生成一次

## 6. 设置说明

| 设置 | 说明 |
| --- | --- |
| 主题 | 亮色 / 暗色 / 跟随系统 |
| 默认 Provider | 新建会话时默认使用 |
| Chunk Size | 文本分块大小（默认 500 字） |
| Chunk Overlap | 块重叠（默认 50 字） |
| Top-K | 检索返回的片段数（默认 5） |
| Temperature | 回答随机性（0-1，默认 0.7） |
| 自动启动 | 开机自启 |
| 语言 | 中文 / English |

## 7. 常见问题

**Q1：启动后弹出「向量库启动失败」？**
A：本版本（v1.1）使用纯 JS 向量库 vectra，不再有"启动失败"对话框。若遇到索引错误，可删除 `%APPDATA%\LocalRAG\index\` 目录后重启应用（会触发重建）。

**Q2：API Key 在哪保存？**
A：Windows 凭据管理器（控制面板 → 用户账户 → 凭据管理器 → Windows 凭据）。**不会**以明文保存到任何文件。

**Q3：能否离线使用？**
A：上传过的文档和已生成的向量数据完全离线可用；仅在「对话」与「首次上传」时需要联网调用 Embedding。

**Q4：上传超大 PDF 怎么办？**
A：建议拆分后分批上传；单文件超过 200 MB 可能被系统 OOM 杀死。

**Q5：如何彻底卸载？**
A：控制面板 → 卸载程序。卸载时可选择「同时删除数据目录」以清空所有知识库。

**Q6：能否更换数据存储位置？**
A：可以通过快捷方式的「目标」追加 `--user-data-dir="D:\MyRagData"`。

**Q7：知识库数据怎么备份？**
A：备份整个 `%APPDATA%\LocalRAG\` 目录即可（包含 SQLite + 向量索引 + 配置）。注意 API Key 存在 Windows 凭据管理器，备份目录里不包含。

**Q8：与之前版本的 ChromaDB 版本能共存吗？**
A：不能。两套数据格式不同。升级到 v1.1 后需要重新上传文档。

## 8. 数据存储位置

| 数据 | 路径（Windows） |
| --- | --- |
| 应用配置 / 数据库 | `%APPDATA%\LocalRAG\config.json` |
| 对话历史 | `%APPDATA%\LocalRAG\chat.db` |
| 向量索引 | `%APPDATA%\LocalRAG\index\<kbId>\`（每知识库一个目录） |
| 缓存 | `%APPDATA%\LocalRAG\cache\` |
| 日志 | `%APPDATA%\LocalRAG\logs\` |
| API Key | Windows 凭据管理器（条目名 `LocalRAG/<provider-id>`） |
